# Riley Strauman | Developer Portfolio

Personal developer portfolio built with React and Vite, showcasing projects, games, tech stack, and background.

**Live site:** https://rstrauman.github.io/Rileys-Portfolio/

## Sections

- **Header** — intro, headshot, location, social links
- **Technologies I Use / Languages I Program With** — tech stack with icons (via [devicon](https://devicon.dev/))
- **About Me** — background and current focus
- **Projects** — auto-scrolling carousel of web app projects, each with a screenshot, description, and GitHub/live demo links
- **Games** — Unity games built and shipped as WebGL builds
- **My Tech Journey** — timeline from first learning to program through to studying Software Development at MITT
- **Fun Facts** — a few personal details
- **Contact** — email, resume download, and social links

## Tech Stack

- [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/) (CSS-first config via `@tailwindcss/vite`)
- [Framer Motion](https://www.framer.com/motion/) for animated components
- [AOS](https://michalsnik.github.io/aos/) for scroll animations
- [devicon](https://devicon.dev/) for tech stack icons

## Running Locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:3000`.

## Building & Deploying

```bash
npm run build     # builds to dist/
npm run deploy     # builds, then publishes dist/ to the gh-pages branch
```

Deployed via [`gh-pages`](https://github.com/tschaub/gh-pages) to GitHub Pages.
